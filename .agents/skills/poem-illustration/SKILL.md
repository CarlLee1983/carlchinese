# 逐首詩配圖

本技能只管理本專案的作品插圖。每件可讀作品各有獨立意境圖；首頁選詩與作品頁讀取同一筆對應。只列在目錄、尚無內容的作品不批次生成。專區圖、首頁山水與共用梅枝屬裝飾，不能算作逐首配圖。

## 先確定作品與範圍

從專案根目錄工作，依 `docs/agents/domain.md` 讀取領域文件與相關作品全文。確認正式作品識別、組詩其序、正文異文及解讀層次；以「系列＋底本序號」綁定圖片，題名或陣列位置不作唯一鍵。組詩每一首分別處理。

依任務區分產圖、接入頁面或只做檢查。只要求流程配置／盤點時，報告缺口，不自動生成全目錄圖片。修改詩文時先比較畫意，只有圖像已不相符才重製。

## 構圖與生成

1. 從正文挑出可支持的物象、情緒及視角，寫出簡短畫意與最終提示詞。現有三篇可從針線與遠行、殘垣與春草、月光與清影發展，各自構圖；題材是參考，不能取代逐篇閱讀。
2. 延續淡宣紙、黑灰水墨、飛白與留白，圖片不嵌入標題、英文、落款或假印章；中文標題與說明由頁面排版。保持視覺家族一致，但不以同一張山水重複充當不同作品的專屬圖。
3. 插圖是意境創作，不作史實證據。正文未確定的年代、人物面貌、地點與器物形制避免畫成考據結論；有異文時配合本頁採用正文。戰爭與離別題材維持親子可讀的含蓄表達。
4. 使用環境中可用的 `imagegen` skill 與內建圖片生成工具。生成後逐張看圖，檢查詩意、文字殘留、人物肢體、物件與構圖；工具失敗時如實標記未完成，不以共用裝飾替代，也不擅自改用需憑證的服務。
5. 將選定素材放進專案 `public/art/poems/<系列>/<三位底本序號>-ink.webp`。替換時先保存新版本，確認引用切換後才清理本任務取代的舊素材；保留他人未提交工作。記錄生成工具、提示詞、原始輸出位置、作品對應及選用理由，放在本次 `docs/evidence/` 記錄中。

## 接入與資料契約

先找既有圖片對應入口；存在就擴充，不另建平行清單。每筆對應至少能取得圖片路徑、繁體中文替代文字及固有尺寸，依穩定作品識別查找。首頁預覽與作品頁使用同一來源，切換作品時圖片、題名與閱讀連結必須一致。

本專案的對應入口為 `src/content/illustrations.mjs`，由 `loadSiteContent()` 供兩種頁面共用；檢查範圍與 fixture 例外見 `docs/toolchain.md` 的「作品插圖」。更新這個入口，不把圖片欄位直接寫入尚未支援它的 frontmatter。

作品插圖旁標示「意境插圖・人工智慧生成」，替代文字描述實際畫面。圖片與詩文分開排版，保留詩句可讀性；設固有尺寸避免載入跳動，首屏主要圖與頁下延遲載入分別處理。柔邊遮罩、墨色混合可用於融合紙面，重要物象不能因裁切消失；減少動態偏好與無腳本模式仍能閱讀。

## 完成條件

逐首交付須同時具備：

- 專屬素材已保存、可解碼、無重複誤配，圖片與詩意已人工目視檢查；提示詞與來源記錄可追溯。
- 首頁與作品頁同一作品顯示同一張圖；首頁切換、直接片段網址、瀏覽歷史及無腳本閱讀不破壞對應。
- 手機與桌面實際載入截圖可讀、無水平溢出、無文字被裝飾遮擋；替代文字與意境創作標示完整。
- 當建立／修改對應驗證時，覆蓋缺圖、錯誤識別、重複共用、檔案不存在及可成功載入的案例；正式驗證只要求可讀作品，隔離組詩 fixture 使用測試資產或明確測試資料，不要求生成真實插畫，也不進入正式網站。
- 依 `docs/toolchain.md` 完成受影響檢查與完整整合驗證，報告逐首完成／缺圖／待接入狀態。只完成圖片或 skill，不宣稱整個配圖流程已驗收；本 skill 本身不是建置強制閘門。
