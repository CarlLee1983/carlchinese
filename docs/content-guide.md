# 作品頁寫作指南

> v1.0，2026-10-15 內容規格定稿。三篇樣章已通過文字結構檢查，來源補證與實際親子試讀仍待驗收；交接範圍及待辦見[閱讀頁交接](reading-page-handoff.md)。欄位格式見 [content-schema.md](content-schema.md)，用語以 [CONTEXT.md](../CONTEXT.md) 為準。

## 作品頁與篇幅

一件作品一頁，依序為原文、深入賞析、親子共學。家長先讀懂作品，再帶孩子讀。

- 以五、七言絕句為基準，深入賞析不超過 1,500 字；律詩與古體詩可放寬到 1.5 倍。
- 親子共學整段講述控制在 15 分鐘內，約 1,200 字。15 分鐘對所有體裁都是硬性上限；長篇古體詩可只挑段落帶讀。

## 原文

- 包含標題、作者、朝代、帶現代標點的詩句全文、需標讀音的字、押韻古讀註、異文，以及有據可查的題下注。底本題名與通行題名不同時另記底本題名；題名差異不當作題下注。
- 正文由多種文本互校而成，逐篇記下實際互校的文本與卷次（校字依據）。底本只決定篇目、序號及體裁欄，不宣稱正文出自底本；其他版本的體裁分類在賞析交代。
- 正文每句一行，使用本站加上的現代標點。頁面統一聲明「標點為本站編輯所加」；這是呈現規則，不需假託古籍出處，也不將標點當成校字來源。影響解讀且有爭議的標點，在賞析交代觀點及依據。
- 單純異體字統一為臺灣正字，在文字註記說明，不列作異文；涉及字義差異的字形則列異文。通行正文若晚於其他留存文字，在原文區提醒讀者通行文字不等於作者原貌，不把 `variants` 排列當成原文真偽或先後的證明。
- 正文版本異文與古書明記的「一作」列入異文欄，分別標示「正文」或「一作」及其出處；同一讀法若有兩種身分，分成兩筆。詩話偶然引句的差異留在賞析，不當作正文異文。題下注另記文字及出現版本、位置；某版本標作「自註」只表示該版本這樣標，不證實作者親註，也不能單憑它斷定寫作年代。
- 讀音採教育部審定音，只標需標讀音的字，不做全文注音。兩類需標字為：
  - **難字**：沒出現在教育部《國小學童常用字詞調查報告書》表二十五第 1–8 冊的字。表內的字若有理由需要標（如字形易混），可補標並寫明理由。
  - **破音字**：依教育部《國語小字典》是多音字，且本句讀音不是網站列的第一音。例如「不勝」的「勝」讀ㄕㄥ。網站與下載 XLSX 的排序不一致時，依網站第一音；〈遊子吟〉的「縫」已驗出這種差異。
  - 兩份資料只在寫作時查詢，不放進 repo，也不在頁面轉載。
- 押韻處若今音不押韻，另註古讀。依據由高到低可接受三級：教育部審訂附註、教育部辭典的又音或讀音、韻書反切（《廣韻》）。用第二級以下的依據時，註裡要寫出韻部與同韻腳字。
- 原文區免標段落層次；讀音、押韻古讀、異文、題下注及文字註記的每一項均以具體來源支撐，展示時附出處與查核狀態。讀了錄文就記「僅核錄文」，查了書影才記「已核書影」；網址本身不代表已核書影。無從追溯舊稿查核狀態時記「未記錄」並說明，不能補猜。

## 深入賞析

寫給成人讀者，也是家長的備課材料。固定子標題如下：

1. **字詞**（必寫）：只挑會影響理解的詞，不逐字翻譯。
2. **背景**（必寫）。
3. **技巧**（必寫）。
4. **情感**（必寫）。
5. **比較閱讀**（選寫）：沒有自然的比較對象就省略。

## 親子共學

家長可以直接照著唸給孩子聽。預設孩子第一次讀這首詩，不預設他已經會背。

- 以家長口吻直接對孩子說話，稱呼孩子為「你」；每句不超過 25 字，避免文言詞彙。
- 沉重題材可以說出戰爭、分離、悲傷，但不描述死亡、飢餓、殺戮細節。史實完整寫在深入賞析，由家長決定是否補充。
- 家庭題材忠於詩中的人物關係，例如詩中母親就說母親；連結孩子經驗時可問「照顧你的人」，不預設孩子的家庭組成。提問允許孩子想像詩中人物回答或跳過，不要求透露家事；不把孝順、報恩當成孩子必須給出的答案。

四個區段依序為：

1. **開場**：從孩子生活經驗切入，不用「今天我們要學……」開頭。
2. **共讀**：帶孩子一句一句讀懂作品。
3. **提問**：依 PIRLS 四層理解歷程出題，每層至少一題：提取、推論、詮釋整合、評估。每題附 2–3 個孩子可能的回答，每個回答各配一句家長怎麼接，不提供標準答案。
4. **表達活動**：以口說和仿寫一、兩句童詩為主，畫圖與演出可選；不用背誦或默寫當活動。

## 標示層次與出處

### 段落粒度

- 以段落為單位，一段只能屬於一種標示層次。混了不同層次就拆段；兩說並陳可拆為「通行說法」及「本站觀點」。同一層次可合段引多個不同時代的來源，只要文字說清各來源支持的對象，不因時代不同而硬拆。
- 原文區免標；親子共學的開場與共讀逐段標示。提問與表達活動整體預設為教學想像，不逐題標示。提問需要的史實應先在共讀段講出並標好，提問只引用它。

### 史實

- 只陳述有可查核來源支持的事實，常識性事實也需出處；若不影響理解，可以刪去。每段列明具體來源、位置及該來源支持的事，不能只列一本書讓讀者猜。多個來源不表示每個來源支持段中所有句子。
- 流傳甚廣但不可靠的軼事，只陳述「某文獻記載了此事」，並交代文字與事件的距離。未讀到來源的流行說法不收。
- **繫年**：只在作品本身或事件同時代文獻明確寫日期時，直接陳述事件日期。後代注家繫年則寫「某注家把此詩繫於某時」。無可靠繫年便省略年份；必要時說「本文未採確切繫年」，不斷言無從考證。題下注「自註」不能單獨確定繫年。
- **字義與格律**：有辭典或注本訓釋的字義標史實；找不到依據的字義標本站觀點。體裁、平仄、韻部與推得的格律分類，只有在依據、推導步驟、適用規則均清楚時才標史實，並寫明依何規則判定；未查核或有爭議的分類標本站觀點。格律造成的效果屬文學解讀。`form` 固定依底本；其他分類在賞析交代。
- **他詩引文**：作者寫過某詩、某版本收有某句，依實際收錄文獻標史實；詮釋另起文學解讀段。署名有兩屬就列各版本的署名，不自行裁定作者。人名或引文字形有疑，按實際讀本記並明示不確定性，不自行補正或認定轉引人物身分。

### 出處登錄與時代

- 每篇在 frontmatter 的 `sources` 登錄實際讀過的材料，以 ID 引用。每筆分開記書名／材料、具體卷次篇名或頁碼、出處時代、查核狀態，以及可選的公開連結與補充說明。轉引時，來源仍是實際讀過的那本書；轉引對象在說明或段落中交代。不同來源各有自己的 ID，不用分號串欄位。
- 出處時代分為 **前代文獻、同時代、後世古籍、現代資料**。這是相對於作品及所談事件的文字距離，不是可靠度。**待考**只用於時代無法判定，必須說明疑點，不把它當成第五種實際時代。
- 引用作者的文字，看那段文字形成的時代；討論題注、異文或書籍版本，看被談版本的年代。同一本書若在兩種陳述中角色不同，可以登錄兩筆來源 ID，分別交代所指對象及時代。
- 「同時代」指事件當時形成的文字，或當事人對親歷事件的記述；同一朝代不夠。晚年追記傳聞，即使仍在唐代，也不因朝代相同而算同時代。日期不明時保留不確定性，不能強判。
- 查核狀態是 **已核書影、僅核錄文、未記錄**。「未記錄」用來保留舊稿未載查核程度的情況，必須說明；不能從連結推定已核書影。資料本身的字形有疑時，也在說明或段落明示。

### 文學解讀與教學想像

- 文學解讀分 **通行說法、白話轉述、本站觀點**。通行說法至少引用一位實際讀過的注家或一本注本；白話轉述是逐句用白話說詩意，可以不附出處；新增人物動機或特殊解釋的部分另標本站觀點。本站觀點有實際支撐材料時可列來源，不為填欄而附無關來源。
- 公版古籍（史書、詩話、清代以前的注本）可短句直接引用，標「」並在文中交代出處。仍受著作權保護的現代注本與研究只取觀點，不抄文句；文字重疊不得達 12 字（比照 CarlKitchen ADR 0009）。
- 教學想像的文字本身要讓人聽得出是想像，如「我們來想像……」「如果你是……」；家長唸出來時，孩子看不到標籤。

### 頁面呈現

標示在深入賞析與親子共學、手機與桌機都常駐呈現，不提供隱藏開關。段落左側以四種顏色區分：史實、文學解讀（通行說法與白話轉述共用實線色）、本站觀點（同屬文學解讀，但色條為虛線）、教學想像。色條上方寫完整層次名稱，例如「文學解讀・白話轉述」。頁首圖例說明四種顏色。

史實的來源時代在段末逐筆顯示，不用不同時代製造新顏色，也不在段落標籤只顯示一個時代。凡有來源的段落，段尾直接列各筆來源、具體位置、時代及查核狀態；有連結時附連結，不藏在按鈕或註腳。原文區的校字、讀音、押韻、異文、題注與文字註記也展示所引來源及查核狀態。
