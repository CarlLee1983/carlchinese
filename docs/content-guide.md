# 作品頁寫作指南

> v0.1 草稿，待樣章驗證。規則來源：[教材規格骨架：作品頁區塊、標示層次規則與欄位](../.scratch/carlchinese/issues/04-material-spec-skeleton.md)、[規格 v0 第一輪修訂](../.scratch/carlchinese/issues/10-spec-revision-round1.md)。欄位格式見 [content-schema.md](content-schema.md)，用語以 [CONTEXT.md](../CONTEXT.md) 為準。

## 作品頁的區塊與順序

一件作品一頁，依序為原文、深入賞析、親子共學。順序依家長的備課順序：先讀懂作品，再帶孩子讀。

## 篇幅

以五、七言絕句為基準：

- 深入賞析不超過 1,500 字；律詩與古體詩可放寬到 1.5 倍。
- 親子共學整段講述控制在 15 分鐘內，約 1,200 字。15 分鐘對所有體裁都是硬性上限，不隨詩體放寬，字數只是參考。長篇古體詩的共讀可以只挑段落帶讀。

## 原文

- 包含標題、作者、朝代、詩句全文、需標讀音的字、押韻古讀註、異文。
- 正文由多種文本互校而成，逐篇記下實際互校的文本與卷次（校字依據）。底本只決定篇目與序號，不宣稱正文出自底本。
- 讀音採教育部審定音，只標需標讀音的字，不做全文注音。需標讀音的字有兩類：
  - **難字**：沒出現在教育部《國小學童常用字詞調查報告書》表二十五第 1–8 冊的字。表內的字若有理由需要標（例如字形易混），作者可以補標，但要寫明理由。
  - **破音字**：依教育部《國語小字典》是多音字，且在本句的讀音不是第一音，例如「不勝」的「勝」讀ㄕㄥ。
  - 兩份資料只在寫作時查詢，不放進 repo，也不在頁面上轉載。
- 押韻處若今音不押韻，另註古讀。依據由高到低可接受三級：教育部審訂附註、教育部辭典的又音或讀音、韻書反切（《廣韻》）。用第二級以下的依據時，註裡要寫出韻部與同韻腳字，例如「侵韻，與深、心、金同押」。
- 異文另欄註記：記下在第幾句，以及哪本書記載了這個異文（例如「《全唐詩》注一作」）。

## 深入賞析

寫給成人讀者，也是家長的備課材料。固定子標題如下：

1. **字詞**（必寫）：只挑會影響理解的詞，不逐字翻譯。
2. **背景**（必寫）
3. **技巧**（必寫）
4. **情感**（必寫）
5. **比較閱讀**（選寫）：沒有自然的比較對象時就省略，不要湊。

## 親子共學

家長可以直接照著唸給孩子聽。寫作時預設孩子第一次讀這首詩，不預設他已經會背。

### 共通寫法

- 以家長的口吻直接對孩子說話，稱呼孩子為「你」。
- 每句不超過 25 字，避免使用文言詞彙。
- **沉重題材**：可以說出戰爭、分離、悲傷這些處境與情緒，但不描述死亡、飢餓、殺戮的細節。這些史實完整寫在深入賞析，由家長自行判斷要不要補充。

### 四個區段

1. **開場**：從孩子的生活經驗切入，不用「今天我們要學……」開頭。
2. **共讀**：帶孩子一句一句讀懂這首詩。
3. **提問**：依 PIRLS 的四層理解歷程出題，每層至少一題：提取、推論、詮釋整合、評估。每題附 2–3 個「孩子可能的回答」，每個回答各配一句「家長怎麼接」，不提供標準答案。
4. **表達活動**：以口說和仿寫一、兩句童詩為主，畫圖與演出可選用。不可用背誦或默寫當作活動。

## 標示層次

### 粒度

- 以段落為單位，一段只能屬於一種標示層次。一段裡混了兩種層次，就拆成兩段。兩說並陳時，拆成「通行說法」與「本站取捨」兩段。
- **例外：原文區塊免標。** 原文本身不屬於任何一種層次；讀音註、押韻古讀註、異文註一律視為史實，來源填字典名或版本名。
- **親子共學**：開場與共讀逐段標示；提問與表達活動整體預設為教學想像，不逐題標示。提問如果需要用到某項史實，這項史實要先在共讀段講出並標好，提問只引用它。

### 史實

- 只陳述有可查核來源支持的事實。
- 流傳甚廣但不可靠的軼事，不直接當作事件來陳述，只陳述「某文獻記載了此事」這個事實，並交代這份文獻與事件之間的距離。例如「《唐才子傳》記載……，這本書成書時，李白已過世五百多年」。
- **繫年**：作品的寫作年代一律寫成「某注家把此詩繫於某時」，出處就是那本注本。只有作品本身或同時代文獻寫明日期時，才把日期當成事件直接陳述。
- **字義與格律**：有辭典或注本訓釋可依的字義，標為史實，出處寫該辭典或注本；體裁、平仄、韻部等可查核的格律事實，標為史實，出處寫韻書或格律依據。對仗、格律「造成什麼效果」屬文學解讀。找不到依據的字義標為本站觀點。
- **他詩引文**：比較閱讀或背景引用作者其他作品時，「作者寫過某詩、詩中有某句」屬史實，出處寫收錄的文獻；對那首詩的詮釋另起一段，標為文學解讀。
- 每段都要附上來源：文獻名、篇卷或頁碼、可公開查閱的連結（有的話），以及出處時代——同時代、後世古籍、現代研究三者之一。

### 出處的寫法

- 出處寫實際讀過的那本書。轉引的對象放在括號裡，例如「仇兆鰲《杜詩詳註》卷四（引黃鶴、趙氏、顧宸）」；不寫自己沒讀過的原書。
- 彼此獨立的多個出處用「；」分隔。

### 文學解讀

- 每段必須標出這是「通行說法」還是「本站觀點」。
- 標為通行說法時，至少要列出一位注家或一本注本作為出處。
- **引文**：公版古籍（史書、詩話、清代以前的注本）可以短句直接引用，加「」並在文中交代出處。仍受著作權保護的現代注本與研究只取觀點，不抄文句，文字重疊不得達 12 字（比照 CarlKitchen ADR 0009）。

### 教學想像

- 段落文字本身就要讓人聽得出這是想像，例如「我們來想像……」「如果你是……」，不能只靠頁面上的標籤。家長唸出來的時候，孩子看不到標籤。

### 頁面呈現

標示層次在頁面上一律用邊條色塊呈現，深入賞析與親子共學相同，手機與桌機也相同：

- 每段左側一條色條，四種標示各用一色：史實、文學解讀・通行說法、文學解讀・本站觀點、教學想像。本站觀點的色條用虛線，與通行說法區分，不只靠顏色。
- 色條上方以小字寫出層次全名，史實另附出處時代，例如「史實・後世古籍」。
- 有出處的段落（史實、通行說法）在段尾直接列出出處，不收進按鈕或註腳。
- 頁首放一列圖例，說明四種顏色。
- 標示一律常駐顯示，不提供隱藏開關。
