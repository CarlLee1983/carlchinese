# 底本序號作為系列內的穩定識別

2026-10-15，已接受。《唐詩三百首》採四藤吟社 313 首本，以「系列＋底本序號」識別作品；檔名與網址仍含通行題名，但題名不負責消除同名作品的歧義。底本決定篇目與排序，正文則由多種文本互校，避免把未取得的底本全文宣稱為實際校字來源。

以題名識別較直觀，卻無法穩定區分同題多首及通行題名與底本題名差異；另設無關序號雖能脫離選本，卻失去目錄次序的對照。選用底本序號後，更換底本可能影響內容對應與既有連結，因此不得直接重編已使用的識別；若確需更換，須先規劃對照與連結遷移。

具體欄位與檔名格式以 [schema](../content-schema.md) 為準，本 ADR 留存取捨，不另定一套欄位規則。

## Falsified if

若核對發現採定版本無法提供唯一、可重現的篇目序號，或系列需求改成同時呈現多個無法一對一對應的選本，應重新檢討此識別方式；修改題名或校正文句本身不構成重編序號的理由。
