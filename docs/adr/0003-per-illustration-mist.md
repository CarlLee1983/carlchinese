# 水墨煙霧逐圖標示，室內場景不加霧

2026-10-26，已接受。首頁主視覺、專區圖與作品插圖的常駐煙霧不一律套用；每張圖由人判定霧停在哪一帶，主場景在室內的圖（例如〈遊子吟〉屋內縫衣、〈靜夜思〉屋內望月）不加霧，即使門窗外看得到遠景也一樣。作品插圖的判定寫在 `src/content/illustrations.mjs` 每筆的必填欄位 `mist`，值是霧帶的圖片百分比範圍，或以 `null` 明示「判斷過，不加霧」；站方裝飾用圖的霧帶由使用它的頁面傳給 `src/components/InkMist.astro`。

設計原型比較過整張套霧：實作最省事，但室內也起霧在畫意上說不通，而且霧會蓋住人物等重要物象。逐圖判定要多一個必填欄位，換圖時也要重新判斷，我們接受這些成本，換來每張圖的霧都合乎畫意。這個欄位設為必填，新增作品時就不會漏掉這項判斷；看起來像漏做的 `null` 其實是刻意的決定，不要「補齊」成全部加霧。

換圖時重新判定的步驟見[逐首詩配圖技能](../../.agents/skills/poem-illustration/SKILL.md)。

## Falsified if

若實際讀者或試讀家長反映，室內圖缺少煙霧讓網站看起來不一致，或有霧的室外圖反覆因霧帶遮住重要物象而必須改圖，應重新檢討逐圖判定規則。若 `src/content/illustrations.mjs` 改為不再逐筆記錄 `mist`，或 `src/components/InkMist.astro` 改成不讀逐圖資料就一律套霧，代表本決定已被推翻，須先修訂本記錄。
