# 段落標示層次與有據陳述的來源必填

2026-10-15，已接受。作品頁將史實、文學解讀、教學想像分開標示，對需要依據的內容強制記錄來源。親子共學的家長可能直接照讀，因此不能只在頁尾概括聲明「部分為想像」，讓具體段落的性質仍不明。

只標整個區塊比較省事，也較少切斷閱讀，但同一區塊常同時包含史事、詮釋與虛構情境；完全不標則更難分辨。選擇段落粒度，接受拆段、查證與維護來源的成本，讓讀者能定位每項陳述的性質與依據。大量內容依此編寫後，取消分類或改粒度需要重新審讀，不能只換呈現樣式。

原文及提問／活動的既定例外、各類來源要求與呈現細節以[寫作指南](../content-guide.md)和 [schema](../content-schema.md) 為準。白話轉述及無引用的本站觀點不為填欄而虛設來源；來源必填不代表所有段落都必須引書。

## Falsified if

若實際共讀反覆顯示，段落標示使讀者更難區分事實與想像，或重要內容必須頻繁違反一段一層才說得清楚，應重新檢討粒度與呈現。若提出替代方式，須先以同一批樣章證明辨識效果，不能只以少填欄位為由移除可追溯性。
