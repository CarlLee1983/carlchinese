## 第一版範圍

網站資訊層級沿用「專區 → 系列 → 作品／詞條」，首頁以專區為入口；本次交付的內容頁是《唐詩三百首》的系列目錄及三篇作品。其他專區的定位可供入口說明，但不因此建立尚無規格的詞條頁或擴寫其他系列。

作品頁依序顯示原文、深入賞析、親子共學，並落實指南的層次色條、文字標籤、來源及查證狀態。需提供回系列目錄、上一篇／下一篇，以及原文／深入賞析／親子共學的頁內跳轉。

前後篇按底本序號，只連到已有可讀內容的作品；以現有資料驗收時為〈遊子吟〉40 →〈春望〉98 →〈靜夜思〉226。未完成的作品不產生空白閱讀頁，首尾邊界不得連向不存在的作品。組詩保留同組互連與共幾首的規則，可點擊目標同樣須已有內容。

系列目錄依原書卷次及體裁分組，已收錄完整 313 首篇目與版本說明；只有三篇有可讀教材，其餘 310 篇不產生空白閱讀頁。版本與補入作品的處理見[內容地圖](content-map.md)及[篇目核對記錄](catalog-provenance.md)。

第一版不包含親子難度／主題路線、全站親子入口、生活國語交叉連結、作者頁、主題頁、其他年齡版本、插圖、朗讀或 CMS。這是第一版的歷史交付範圍；後續逐首插圖範圍已依[內容地圖](content-map.md)調整。公開部署與網域另行決定。

實作驗收至少包含：

- 依 schema 驗證必填欄位、作品序號與檔名、引用 ID、列舉值、未知狀態說明、異文句序、段落包覆、標題順序及提問結構；錯誤資料須清楚指出檔案與位置，不可靜默遺漏。
- 三篇真實樣章均能完整渲染原文、讀音、押韻、異文、題注、文字註記及來源。有據陳述的出處逐筆對應；白話轉述與通行說法共色但文字標籤不同，本站觀點維持虛線；標示與來源在手機及桌機都可讀。
- 驗證回目錄、前後篇、頁內跳轉與缺篇邊界。三篇樣章沒有組詩，須另以最小測試資料驗證組詩關係與未完成成員；測試資料不當成公開教材。
- 用實際選定的解析器驗證中文 directive 與提問 YAML 能正確處理，不把 schema 的示例當成已通過解析器測試。

現用 Astro 7.3.8、Node 24.21.0、pnpm 12.0.0 與 Playwright 1.64.1；安裝與實際指令見[本地工具鏈](toolchain.md)。`pnpm run verify` 串起 Astro 檢查、正式內容驗證、Node 測試、正式靜態建置、隔離的組詩 fixture 建置與瀏覽器測試，以及正式版瀏覽器測試。正式產物在 `dist/`；含私有測試資料的 `dist-group-fixture/` 只供驗收，不作部署。專案未設定公開部署或 CMS。
