# 水墨圖片與筆觸補充

延續上一輪全滿版中文介面，新增兩幅圖片與可重用的筆觸素材。修改範圍為 `src/pages/index.astro`、`src/styles/site.css` 及以下三個素材，沒有新增套件或更動內容資料、閱讀與導覽邏輯。

- [筆墨書案](../../../public/art/writing-desk-ink.webp)：生活國語專區插畫。
- [山嵐榕影](../../../public/art/taiwan-ink.webp)：臺灣文學專區的想像風景，不指涉特定古蹟或歷史場景。
- [飛白筆觸](../../../public/art/brush-stroke.svg)：以靜態向量路徑、紋理與位移濾鏡繪製，供章節、目錄卷次及頁尾裝飾。

兩幅插畫由內建 image_gen 工具生成，完整[提示詞](prompts.json)已保存。以 cwebp 品質 85 編碼為網站使用的圖片，合計約 455 KiB，標示固有尺寸並採延遲載入與非同步解碼。圖片加入徑向柔邊遮罩及色彩混合，首頁主畫幅加入底部漸隱。桌面專區採錯落高度，手機改回順序排列。圖片替代文字為繁體中文；裝飾筆觸不加入讀屏內容。

[完整驗證](verify.log)通過：Astro 檢查、內容驗證、44 項 Node 測試、正式建置、隔離組詩建置與 2 項測試、30 項正式瀏覽器測試。獨立唯讀審查無實質問題，差異空白檢查通過。

[尺寸與載入檢查](inspection.json)涵蓋 320、390、768、1440、1920 像素，兩張圖片均成功解碼，首頁無水平溢出或拉丁文字。已檢視桌面、平板與手機的新圖區及手機完整頁面。
