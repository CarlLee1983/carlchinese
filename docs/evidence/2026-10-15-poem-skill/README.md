# 逐首詩配圖流程配置

使用者要求把逐首獨立插圖納入專案 skill，讓後續作品有一致處理流程。盤點時專案沒有 `.agents/skills/` 或 `.codex/` 專屬流程；已安裝的通用 imagegen 與視覺設計技能不管理本專案作品識別、逐首對應與閱讀頁驗收。現有共用山水／梅枝與專區插畫不是逐首詩配圖，正式內容模型亦無插圖欄位。

主控制面採用專案內的 [poem-illustration skill](../../../.agents/skills/poem-illustration/SKILL.md)，[AGENTS.md](../../../AGENTS.md) 只放觸發入口。[內容地圖](../../content-map.md) 更新舊版排除插圖的範圍，完整操作規則只保留在 skill。不修改全域設定、hooks 或執行權限。

驗證：技能 quick_validate 通過；相對連結、介面描述長度及預設呼叫名稱檢查通過；git diff --check 通過。本輪只有指引與文件，沿用上一輪未變更應用程式的完整驗證結果，不重跑網站測試。獨立新上下文代理的行為試跑結果另記於下方。

這是流程約束，不是已接入建置的缺圖閘門。現有三首詩仍待各自產圖、建立共用對應及接入首頁／作品頁；不能把 skill 配置完成當成逐首配圖完成。新會話可由 AGENTS.md 入口讀取技能；目前會話未宣稱技能選單已熱載入。

回復方式：移除本次新增的 `.agents/skills/poem-illustration/`，刪除 AGENTS.md 的配圖入口，將內容地圖的本次範圍修訂回復。保留其他未提交成果與既有圖片。此次未提交、推送或部署。
