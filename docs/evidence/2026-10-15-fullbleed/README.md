# 全滿版書法水墨調整

本輪承接既有未提交的水墨版面，修改共用頁首、首頁、目錄與作品頁的品牌文字及樣式，並同步中文化舊網址頁籤。新增淡宣紙紋理，沒有新增依賴或更動作品內容、網址與資料模型。

頁首站名改為「讀中文」，搭配朱印；首頁畫幅及頁面外層取消固定最大寬度，章節與頁尾放大書法字級。長篇內文維持閱讀行寬。七百像素以下將首頁介紹移至畫幅下，避免與圖中文字重疊。水墨背景使用變暗混合，融合素材底色與頁面宣紙色。
