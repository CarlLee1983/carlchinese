## 深入賞析

### 字詞

:::史實{refs="moe_revised_1 moe_variants_1"}
「床」是供人坐臥的器具。古書多寫作「牀」，今日以「床」為正字，「牀」為異體。
:::

:::文學解讀{stance="通行說法" refs="zhang_zhu_shu_2"}
清代章燮串講這首詩時說：「床前則人已睡矣，疑是地上霜則披衣起視矣。」他把「床」理解成睡覺的床：詩人本已躺下，看見地上一片白，才起身細看。
:::

:::文學解讀{stance="本站觀點"}
「疑」在這裡不是懷疑別人，是「一時以為」。月光照在地上，白得像霜，詩人一瞬間錯認了，下一句才抬頭確認那是月亮。
:::

:::史實{refs="moe_concise_2"}
霜是接近地面的水蒸氣遇冷凝結成的白色細微結晶。
:::

### 背景

:::史實{refs="li_yangbing_xu_1 wei_hao_xu_1"}
李白的家族在唐中宗神龍初年遷入蜀地。替李白編集的李陽冰說他家「神龍之始，逃歸於蜀」；同時代的魏顥則寫李白「身既生蜀」。兩篇序文對出生地的說法不同；蜀地與李白早年的關係則見於這些記述。
:::

:::史實{refs="libai_pei_shu_1 libai_du_jingmen_1"}
李白自述年輕時「仗劍去國，辭親遠遊」。他乘船出三峽時寫下〈渡荊門送別〉，末兩句是「仍憐故鄉水，萬里送行舟」。
:::

:::史實{refs="wang_li_taibai_1"}
清代王琦編李白年譜，把出蜀繫於開元十三年（725），但自己注明「其歲月皆無可考」。他又依李白的詩作推斷，李白出蜀之後「不復旋返」。這是王琦的推斷。
:::

:::史實{refs="wang_li_taibai_2"}
本文不採確切繫年。王琦《李太白年譜》未把這首詩繫於某年，不能由此推定寫作時間或地點。
:::

:::史實{refs="li_taibai_wenji_1 yue_fu_shi_ji_1 hu_tang_yin_1 chen_bu_zhu_1"}
李白集把這首詩題作〈靜夜思〉，編在樂府類；宋代郭茂倩《樂府詩集》也把它收進「新樂府辭」。明代胡震亨論樂府題名，舉〈靜夜思〉為以情感命名的例子。《唐詩三百首》題作〈夜思〉，歸在五言絕句。
:::

:::史實{refs="li_taibai_wenji_1 quan_tang_shi_1 gao_tang_shi_1 chen_bu_zhu_1"}
今天通行的文字，和所見李白集的正文不一樣。李白集與《全唐詩》作「床前看月光」「舉頭望山月」；明初高棅《唐詩品彙》已把第三句作「望明月」；《唐詩三百首》兩處都作「明月」，成了後來的通行文字；這不等於李白寫作時的原貌。
:::

:::史實{refs="chen_chong_study_1"}
陳翀考察南宋《海錄碎事》與元代范德機的引文，認為「明月光」「望明月」在明代以前就已流傳，不能把通行文字的形成全歸於明清選家。
:::

### 技巧

:::文學解讀{stance="通行說法" refs="zhang_zhu_shu_2 tang_song_shi_chun_1"}
章燮在「疑是地上霜」下注：「明是月光反疑是霜，所以詩怕直致而喜曲折也。」清人徐增則指出全詩的動作一環扣一環：「因疑則望，因望則思。」錯認、抬頭、低頭、想家，二十個字裡有一整串心理過程。
:::

:::文學解讀{stance="通行說法" refs="shen_tang_shi_1 tang_song_shi_chun_2"}
沈德潛評這首詩：「旅中情思，雖說明卻不說盡。」《唐宋詩醇》所引署名「范杼」的評語也拿它說明五言短詩「不可明白說盡，含蓄則有餘味」。詩人說了「思故鄉」，卻沒說故鄉有誰、為什麼想、想到什麼程度，空白留給讀者。
:::

:::史實{refs="guang_yun_1"}
全詩押平聲韻，韻腳是光、霜、鄉。在《廣韻》裡，光屬唐韻，霜、鄉屬陽韻，兩韻同用。今天國語讀起來也仍然押韻。
:::

:::史實{refs="guang_yun_2"}
依《廣韻》聲調，四句的平仄是：平平平仄平、平仄仄仄平、仄平？平仄（「望」有平、去兩讀）、平平平仄平。「明月」兩字在詩中出現兩次。
:::

:::文學解讀{stance="本站觀點"}
照唐代近體詩的規則，第二句的二、四字同聲，第三句和第二句也不相粘，加上不避重字，這首詩不合近體五言絕句的格律，比較接近不講平仄的古體短詩。它不靠格律取勝，靠的是用字淺白：二十個字裡沒有一個典故、一個難詞。
:::

:::文學解讀{stance="本站觀點"}
「舉頭」與「低頭」是一組相反的動作，中間只隔著一輪月亮。抬頭看見的是眼前的月，低頭想到的是看不見的家；月亮把此地與故鄉連在一起，因為兩地看見的是同一個月亮。
:::

### 情感

:::文學解讀{stance="本站觀點"}
這首詩的鄉愁很輕，沒有眼淚，也沒有嘆息。夜深人靜，一個人看見地上的月光，愣了一下，抬頭，再低頭。想家常常就是這樣：不是時時刻刻記著，而是被一個小小的景象突然勾起來。
:::

:::文學解讀{stance="本站觀點"}
正因為沒有寫明是誰、在哪裡、哪一年，每個離家的人都能把自己放進去。這大概也是它流傳最廣的原因：讀者不需要知道李白的生平，就能讀懂。
:::

### 比較閱讀

:::史實{refs="dufu_yue_ye_1"}
杜甫〈月夜憶舍弟〉也是在月夜想念家人，詩中有「露從今夜白，月是故鄉明」兩句。
:::

:::文學解讀{stance="本站觀點"}
兩首詩都用月亮連起此地與故鄉，寫法卻相反。李白說月光像霜，只寫自己看到的；杜甫明知月亮到哪裡都一樣，偏說故鄉的月比較亮，把思念直接說成了偏心。可以請孩子比比看，哪一種比較像自己想家時的心情。
:::

## 親子共學

### 開場

:::教學想像
我們來想像一下。
一個旅人睡到一半，醒了過來。
房間裡好安靜，大家都睡著了。
這時候，你會聽到什麼？看到什麼？
:::

:::教學想像
再想像你在很遠的地方。
你一個人醒來，會先想到誰？
這首詩寫到夜裡的月光和思念。
:::

### 共讀

:::史實{refs="li_yangbing_xu_1 libai_pei_shu_1"}
寫這首詩的人叫李白，是唐朝的詩人。
早年的記載說，他和蜀地有關。
長大以後，他離開家人，到很遠的地方去。
:::

:::文學解讀{stance="白話轉述"}
我們讀第一句：「床前明月光。」
床前面的地上，照著明亮的月光。
:::

:::史實{refs="moe_concise_2"}
第二句：「疑是地上霜。」
霜是天氣很冷的早上，地上結的一層白白的冰晶。
:::

:::文學解讀{stance="白話轉述"}
月光白白的，鋪在地上。
詩人一時以為地上結了霜。
「疑」就是一時以為。
:::

:::文學解讀{stance="白話轉述"}
第三句：「舉頭望明月。」
「舉頭」是抬起頭。
詩裡的人抬起頭，望見天上的月亮。
:::

:::文學解讀{stance="白話轉述"}
最後一句：「低頭思故鄉。」
「故鄉」就是他從小長大的家鄉。
他低下頭，想起了故鄉。
:::

:::文學解讀{stance="通行說法" refs="tang_song_shi_chun_1"}
很久以前，有人這樣讀這首詩。
他先看錯，所以抬頭看。
看見月亮，又想起家。
四句詩，一句接著一句。
:::

:::史實{refs="li_taibai_wenji_1 quan_tang_shi_1"}
你會看到另一種文字。
在很老的書裡，這首詩有兩個字不一樣。
第一句寫成「床前看月光」，
第三句寫成「舉頭望山月」。
:::

:::教學想像
我們來想像詩裡的人在夜裡。
四周黑黑的，只有地上一片白。
他抬頭看月亮，又低下頭來。
你覺得，他想起家裡的什麼？
:::

### 表達活動

我們來學詩裡抬頭、低頭的動作。
請用「抬頭看見＿＿，低頭想起＿＿」說一句。
例如：「抬頭看風箏，低頭想起故事。」
可以寫想像的人，也可以跳過。

再玩「看錯了」的遊戲。
詩裡的人把月光看成霜。
想像有人把什麼看成了別的東西。
把它說成一句小詩。
