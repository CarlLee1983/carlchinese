## 深入賞析

### 字詞

:::史實{source="教育部《重編國語辭典修訂本》；教育部《異體字字典》" locator="「床」條；「床」字（A02375）" url="https://dict.variants.moe.edu.tw/dictView.jsp?ID=13171" era="現代研究；現代研究"}
「床」是供人坐臥的器具。古書多寫作「牀」，今日以「床」為正字，「牀」為異體。
:::

:::文學解讀{stance="通行說法" by="章燮《唐詩三百首註疏》卷六上"}
清代章燮串講這首詩時說：「床前則人已睡矣，疑是地上霜則披衣起視矣。」他把「床」理解成睡覺的床：詩人本已躺下，看見地上一片白，才起身細看。
:::

:::文學解讀{stance="本站觀點"}
「疑」在這裡不是懷疑別人，是「一時以為」。月光照在地上，白得像霜，詩人一瞬間錯認了，下一句才抬頭確認那是月亮。
:::

:::史實{source="教育部《國語辭典簡編本》" locator="「霜」條" url="https://dict.concised.moe.edu.tw/dictView.jsp?ID=35794&q=1" era="現代研究"}
霜是接近地面的水蒸氣遇冷凝結成的白色細微結晶。
:::

### 背景

:::史實{source="李陽冰〈唐李翰林草堂集序〉；魏顥〈李翰林集序〉" locator="《全唐文》卷四三七；《全唐文》卷三七三" url="https://zh.wikisource.org/wiki/唐李翰林草堂集序" era="同時代；同時代"}
李白的家族在唐中宗神龍初年遷入蜀地。替李白編集的李陽冰說他家「神龍之始，逃歸於蜀」；同時代的魏顥則寫李白「身既生蜀」。李白出生在哪裡，同時代人說法就不一致，但他在蜀地長大，各家沒有異議。
:::

:::史實{source="李白〈上安州裴長史書〉；李白〈渡荊門送別〉" locator="《全唐文》卷三四八；《全唐詩》卷一七四" url="https://zh.wikisource.org/wiki/渡荊門送別" era="同時代；同時代"}
李白自述年輕時「仗劍去國，辭親遠遊」。他乘船出三峽時寫下〈渡荊門送別〉，末兩句是「仍憐故鄉水，萬里送行舟」。
:::

:::史實{source="王琦《李太白集注》" locator="卷三十五〈李太白年譜〉" url="https://zh.wikisource.org/wiki/李太白全集/卷三十五" era="後世古籍"}
清代王琦編李白年譜，把出蜀繫於開元十三年（725），但自己注明「其歲月皆無可考」。他又依李白的詩作推斷，李白出蜀之後「不復旋返」。同時代文獻與兩《唐書》都沒有記載李白回過蜀地，也沒有明說他沒回去。
:::

:::史實{source="王琦《李太白集注》" locator="卷三十五〈李太白年譜〉、卷六" url="https://zh.wikisource.org/wiki/李太白集注_(四庫全書本)/卷06" era="後世古籍"}
李白沒有留下這首詩的寫作時間與地點。王琦年譜沒有收這首詩，其他查過的古籍注本也都沒有替它繫年。
:::

:::史實{source="《李太白文集》（四庫全書本）；郭茂倩《樂府詩集》；胡震亨《唐音癸籤》" locator="卷五〈樂府四〉；卷九十〈新樂府辭〉；卷一" url="https://zh.wikisource.org/wiki/樂府詩集_(四庫全書本)/卷090" era="後世古籍；後世古籍；後世古籍"}
李白集把這首詩題作〈靜夜思〉，編在樂府類；宋代郭茂倩《樂府詩集》也把它收進「新樂府辭」。明代胡震亨論樂府題名，舉〈靜夜思〉為以情感命名的例子。《唐詩三百首》題作〈夜思〉，歸在五言絕句；清代王士禛、沈德潛的選本也作〈夜思〉。
:::

:::史實{source="《李太白文集》（四庫全書本）；《全唐詩》（四庫全書本）；高棅《唐詩品彙》；陳婉俊《唐詩三百首補注》" locator="卷五；卷一六五；卷三十九；卷七" url="https://zh.wikisource.org/wiki/唐詩品彚_(四庫全書本)/卷39" era="後世古籍；後世古籍；後世古籍；後世古籍"}
今天人人會背的文字，和李白集不一樣。李白集與《全唐詩》作「床前看月光」「舉頭望山月」；明初高棅《唐詩品彙》已把第三句作「望明月」；《唐詩三百首》兩處都作「明月」，就是今天的通行本。
:::

:::史實{source="陳翀〈李白「静夜思」本文変遷史新考〉" locator="《広島大学大学院文学研究科論集》78（2018），頁 59–70" url="https://doi.org/10.15027/46864" era="現代研究"}
過去常見的說法是清代王士禛改動了文字。任教於廣島大學的陳翀考察南宋《海錄碎事》與元代范德機的引文，認為「明月光」「望明月」在明代以前就已流傳，不是明清選家所改。
:::

### 技巧

:::文學解讀{stance="通行說法" by="章燮《唐詩三百首註疏》卷六上；《御選唐宋詩醇》卷四（引徐增）"}
章燮在「疑是地上霜」下注：「明是月光反疑是霜，所以詩怕直致而喜曲折也。」清人徐增則指出全詩的動作一環扣一環：「因疑則望，因望則思。」錯認、抬頭、低頭、想家，二十個字裡有一整串心理過程。
:::

:::文學解讀{stance="通行說法" by="沈德潛《重訂唐詩別裁集》卷十九；《御選唐宋詩醇》卷四（引范杼）"}
沈德潛評這首詩：「旅中情思，雖說明卻不說盡。」《唐宋詩醇》所引范杼的評語也拿它說明五言短詩「不可明白說盡，含蓄則有餘味」。詩人說了「思故鄉」，卻沒說故鄉有誰、為什麼想、想到什麼程度，空白留給讀者。
:::

:::史實{source="《廣韻》" locator="下平聲十陽（唐同用）：霜，色莊切；鄉，許良切。十一唐：光，古黃切" url="https://ytenx.org/kyonh/" era="後世古籍"}
全詩押平聲韻，韻腳是光、霜、鄉。在《廣韻》裡，光屬唐韻，霜、鄉屬陽韻，兩韻同用。今天國語讀起來也仍然押韻。
:::

:::史實{source="《廣韻》" locator="各字聲調" url="https://ytenx.org/kyonh/" era="後世古籍"}
依《廣韻》聲調，四句的平仄是：平平平仄平、平仄仄仄平、仄平？平仄（「望」有平、去兩讀）、平平平仄平。「明月」兩字在詩中出現兩次。
:::

:::文學解讀{stance="本站觀點"}
照唐代近體詩的規則，第二句的二、四字同聲，第三句和第二句也不相粘，加上不避重字，這首詩不合近體五言絕句的格律，比較接近不講平仄的古體短詩。它不靠格律取勝，靠的是用字淺白：二十個字裡沒有一個典故、一個難詞。
:::

:::文學解讀{stance="本站觀點"}
「舉頭」與「低頭」是一組相反的動作，中間只隔著一輪月亮。抬頭看見的是眼前的月，低頭想到的是看不見的家；月亮把此地與故鄉連在一起，因為兩地看見的是同一個月亮。
:::

### 情感

:::文學解讀{stance="本站觀點"}
這首詩的鄉愁很輕，沒有眼淚，也沒有嘆息。夜深人靜，一個人看見地上的月光，愣了一下，抬頭，再低頭。想家常常就是這樣：不是時時刻刻記著，而是被一個小小的景象突然勾起來。
:::

:::文學解讀{stance="本站觀點"}
正因為沒有寫明是誰、在哪裡、哪一年，每個離家的人都能把自己放進去。這大概也是它流傳最廣的原因：讀者不需要知道李白的生平，就能讀懂。
:::

### 比較閱讀

:::史實{source="杜甫〈月夜憶舍弟〉" locator="《全唐詩》卷二二五" url="https://zh.wikisource.org/wiki/月夜憶舍弟" era="同時代"}
杜甫〈月夜憶舍弟〉也是在月夜想念家人，詩中有「露從今夜白，月是故鄉明」兩句。這首詩也收在《唐詩三百首》的五言律詩裡。
:::

:::文學解讀{stance="本站觀點"}
兩首詩都用月亮連起此地與故鄉，寫法卻相反。李白說月光像霜，只寫自己看到的；杜甫明知月亮到哪裡都一樣，偏說故鄉的月比較亮，把思念直接說成了偏心。可以請孩子比比看，哪一種比較像自己想家時的心情。
:::

## 親子共學

### 開場

:::教學想像
我們來想像一下。
你在外婆家過夜，睡到一半醒過來。
房間裡好安靜，大家都睡著了。
這時候，你會聽到什麼？看到什麼？
:::

:::教學想像
如果你不是在外婆家，
而是在一個離家很遠很遠的地方，
一個人醒過來，你會先想到誰？
今天這首詩，就是一個人半夜醒來時寫的。
:::

### 共讀

:::史實{source="李陽冰〈唐李翰林草堂集序〉；李白〈上安州裴長史書〉" locator="《全唐文》卷四三七；《全唐文》卷三四八" url="https://zh.wikisource.org/wiki/唐李翰林草堂集序" era="同時代；同時代"}
寫這首詩的人叫李白，是唐朝的詩人。
他在蜀地長大，蜀地大約是現在的四川。
長大以後，他離開家人，到很遠的地方去。
:::

:::文學解讀{stance="本站觀點"}
我們讀第一句：「床前明月光。」
床前面的地上，照著明亮的月光。
:::

:::史實{source="教育部《國語辭典簡編本》" locator="「霜」條" url="https://dict.concised.moe.edu.tw/dictView.jsp?ID=35794&q=1" era="現代研究"}
第二句：「疑是地上霜。」
霜是天氣很冷的早上，地上結的一層白白的冰晶。
:::

:::文學解讀{stance="本站觀點"}
月光白白的，鋪在地上。
李白一下子看錯了，以為地上結了霜。
「疑」就是一時以為。
:::

:::文學解讀{stance="本站觀點"}
第三句：「舉頭望明月。」
「舉頭」是抬起頭。
他抬頭一看，原來是天上的月亮。
:::

:::文學解讀{stance="本站觀點"}
最後一句：「低頭思故鄉。」
「故鄉」就是他從小長大的家鄉。
看著月亮，他低下頭，想起了家。
:::

:::文學解讀{stance="通行說法" by="《御選唐宋詩醇》卷四（引徐增）"}
很久以前，有人這樣讀這首詩：
因為看錯了，所以抬頭看；
因為抬頭看見月亮，所以想起家。
四句詩，一句接著一句。
:::

:::史實{source="《李太白文集》卷五；《全唐詩》卷一六五" locator="卷五；卷一六五" url="https://zh.wikisource.org/wiki/李太白文集_(四庫全書本)/卷05" era="後世古籍；後世古籍"}
告訴你一個小秘密。
在很老的書裡，這首詩有兩個字不一樣。
第一句寫成「床前看月光」，
第三句寫成「舉頭望山月」。
:::

:::教學想像
我們來想像李白躺在床上的樣子。
四周黑黑的，只有地上一片白。
他抬頭看月亮，又低下頭來。
你覺得，他想起家裡的什麼？
:::

### 表達活動

我們來學李白的句子，自己做一句。李白寫「舉頭望明月，低頭思故鄉」。請你也用「抬頭看見＿＿，低頭想起＿＿」說一句話。例如：「抬頭看見天上的風箏，低頭想起和爸爸放風箏的那天。」

接著，我們來玩「看錯了」的遊戲。李白把月光看成了霜。請你說一說，你曾經把什麼看錯成什麼？試著把它說成一句詩，例如：「床邊的衣服堆，我以為是一隻小狗。」
