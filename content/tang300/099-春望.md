## 深入賞析

### 字詞

:::文學解讀{stance="本站觀點"}
「國破」的「破」是被攻破。杜甫寫這首詩時人在長安，城已落入叛軍手中，所以「國破」首先是眼前的京城失陷，再延伸到整個國家的殘破。「山河在」的「在」，字面是還在，語氣卻是「只剩下」。
:::

:::文學解讀{stance="通行說法" by="仇兆鰲《杜詩詳註》卷四"}
「烽火連三月」的「三月」，舊注有兩種讀法。仇兆鰲引宋人黃鶴的看法，認為指季春三月，也就是戰火一直延燒到這年暮春；他同時記下趙氏的另一說，把它算成從叛亂爆發起連續三個月，並引顧宸的考證，指出那個時間點長安尚未失陷，判定趙說不合史實。
:::

:::文學解讀{stance="本站觀點"}
本站採「季春三月」的讀法，但不必把「三」讀死。和下句的「萬金」對照，「連三月」寫的是時間拖得長，「抵萬金」寫的是價值抬得高，兩個數字都在誇張戰亂中的煎熬。
:::

:::史實{source="教育部《重編國語辭典修訂本》" locator="「渾」「不勝」「簪」條" era="現代研究"}
「渾欲不勝簪」：渾，簡直；不勝，承受不了。簪是古人用來綰髮或固定頭冠的頭飾。
:::

:::文學解讀{stance="本站觀點"}
「欲」是快要。杜甫的頭髮少到連一根簪子都快插不住，衰老是寫實，也是愁苦的結果。
:::

### 背景

:::史實{source="《舊唐書·肅宗紀》" locator="卷十" url="https://zh.wikisource.org/wiki/舊唐書/卷10" era="後世古籍"}
天寶十四載（755）十一月，安祿山起兵叛唐；次年六月，哥舒翰兵敗，潼關失守，玄宗出奔往蜀。至德二載（757）九月，官軍收復長安。
:::

:::史實{source="《新唐書·杜甫傳》" locator="卷二〇一" url="https://zh.wikisource.org/wiki/新唐書/卷201" era="後世古籍"}
《新唐書》記載：安祿山之亂時，杜甫避難到三川，家眷安置在鄜州；肅宗即位後，他從鄜州換上粗衣想投奔朝廷，途中落入叛軍手中。至德二年，他逃到鳳翔謁見肅宗，被任命為右拾遺。這部史書成書於北宋，距杜甫過世約三百年。
:::

:::史實{source="仇兆鰲《杜詩詳註》" locator="卷四〈春望〉〈憶幼子〉題下注" url="https://zh.wikisource.org/wiki/杜詩詳註_(四庫全書本)/卷04" era="後世古籍"}
杜甫沒有留下這首詩的寫作日期。清代仇兆鰲引宋人黃鶴的說法，把〈春望〉繫於至德二載三月、杜甫陷在叛軍中的時候；同卷〈憶幼子〉的題下注也說杜甫這年春天在長安。這是注家依詩意與史事推定的年代。
:::

:::史實{source="杜甫〈述懷〉" locator="《全唐詩》卷二一七" url="https://zh.wikisource.org/wiki/述懷一首" era="同時代"}
杜甫自己在〈述懷〉裡回顧這段經歷：「去年潼關破，妻子隔絕久。今夏草木長，脫身得西走。」題下注明是「自賊中竄歸鳳翔」後所作。詩中又說：「自寄一封書，今已十月後。」信寄出後十個月，仍沒有家人的回音。
:::

### 技巧

:::文學解讀{stance="通行說法" by="司馬光《續詩話》"}
北宋司馬光拿這首詩的前四句說明古人作詩「意在言外」。他的解讀是：說山河還在，等於說除此之外什麼都沒了；說草木長得深，等於說城裡沒有人；花和鳥本是讓人愉快的東西，詩人卻見了落淚、聽了心驚，時局如何便不言可喻。詩人不直說「長安殘破」，讓讀者自己推出來。
:::

:::文學解讀{stance="通行說法" by="仇兆鰲《杜詩詳註》卷四"}
仇兆鰲把全詩分成兩半：前四句寫春望所見的景，後四句寫遭亂思家的情。他也引元人趙汸的看法，認為「烽火」句接著「感時」，「家書」句接著「恨別」，前後兩聯一一呼應。
:::

:::文學解讀{stance="本站觀點"}
「感時花濺淚，恨別鳥驚心」可以有兩種讀法。一種把花鳥擬人：花也在流淚，鳥也被驚動。另一種以詩人為主語：看到花，詩人淚水濺落；聽到鳥叫，詩人心頭一驚。兩種讀法並不衝突，詩句的好處正在於主語沒有說死，人和景的界線因此模糊了。
:::

:::史實{source="《廣韻》" locator="侵韻：深，式針切；心，息林切；金，居吟切；簪，側吟切" url="https://ytenx.org/kyonh/" era="後世古籍"}
這是一首五言律詩，押侵韻，韻腳是深、心、金、簪。中間兩聯對仗：「感時」對「恨別」，「花濺淚」對「鳥驚心」；「烽火」對「家書」，「連三月」對「抵萬金」。
:::

:::文學解讀{stance="本站觀點"}
工整的形式裝著紛亂的時局，形式越穩，越顯出內容的不安。
:::

:::文學解讀{stance="本站觀點"}
全詩的視線一路收窄：從山河、城池，到花鳥，到戰火與家書，最後落在詩人自己頭上稀疏的白髮與一根插不住的簪子。國、家、身三層，從最大的寫到最小的，最小的那根簪子反而最刺眼。
:::

### 情感

:::文學解讀{stance="本站觀點"}
這首詩的悲傷有兩個來源：國家殘破，以及與家人斷了音訊。杜甫沒有把兩者分開，也沒有喊口號。他寫的是一個被困在城裡的中年人，在春天看到花開鳥鳴，卻只覺得刺痛。
:::

:::文學解讀{stance="本站觀點"}
結尾不寫報國的決心，而寫自己老了、頭髮少了。這種無力感很誠實：一個人在亂世裡能做的事很有限，能感受到的痛卻很具體。讀者不必把它讀成悲壯，讀成一個父親、一個丈夫的焦慮也成立。
:::

### 比較閱讀

:::文學解讀{stance="通行說法" by="仇兆鰲《杜詩詳註》卷四"}
「不勝簪」的說法有來歷。仇兆鰲在注中引了南朝鮑照的詩句「白髮零落不勝簪」，杜甫的末句與之相近。
:::

:::史實{source="杜甫〈憶幼子〉" locator="《全唐詩》卷二二四" url="https://zh.wikisource.org/wiki/全唐詩/卷224" era="同時代"}
杜甫還寫了〈憶幼子〉：「驥子春猶隔，鶯歌暖正繁。別離驚節換，聰慧與誰論。」
:::

:::史實{source="仇兆鰲《杜詩詳註》" locator="卷四〈憶幼子〉題下注" url="https://zh.wikisource.org/wiki/杜詩詳註_(四庫全書本)/卷04" era="後世古籍"}
仇兆鰲把〈憶幼子〉和〈春望〉繫在同一年春天，並注明驥子是杜甫幼子宗武的小名。
:::

:::文學解讀{stance="本站觀點"}
把兩首詩放在一起讀，〈春望〉的「恨別鳥驚心」就有了具體的臉孔。〈憶幼子〉裡，鶯鳥唱得正熱鬧，提醒他季節又換了，他想的是那個聰明的孩子身邊沒有人可以說話。〈述懷〉裡「反畏消息來」一句，更寫出等家書等到怕收到信的心情，可以和「家書抵萬金」對照著讀。
:::

## 親子共學

### 開場

:::教學想像
我們來想像一下。
你去參加一個很遠的營隊，要住好幾個月。
營隊裡不能打電話，也不能傳訊息。
你會最想念誰？
你會最想知道家裡的什麼事？
:::

:::教學想像
再想像一下，如果外面發生了很危險的事。
你回不了家，也不知道家人好不好。
這時候收到一封家裡寄來的信，你會有什麼感覺？
今天這首詩，就是一個回不了家的人寫的。
:::

### 共讀

:::史實{source="《新唐書·杜甫傳》" locator="卷二〇一" url="https://zh.wikisource.org/wiki/新唐書/卷201" era="後世古籍"}
寫這首詩的人叫杜甫，是唐朝的詩人。
那時候有人帶兵造反，國家發生了大戰亂。
杜甫的太太和孩子住在另一個地方。
他一個人出門，半路上被叛軍抓住了。
:::

:::史實{source="仇兆鰲《杜詩詳註》" locator="卷四〈春望〉題下注" url="https://zh.wikisource.org/wiki/杜詩詳註_(四庫全書本)/卷04" era="後世古籍"}
研究杜甫的學者推算，這首詩寫在那年的春天。
那時候他被困在京城長安，出不去。
詩的名字叫〈春望〉，就是「在春天往外看」。
:::

:::文學解讀{stance="通行說法" by="司馬光《續詩話》"}
我們讀前兩句：「國破山河在，城春草木深。」
京城被打下來了，只剩下山和河還在。
春天到了，城裡的草和樹長得又高又密。
草長那麼高，表示沒有人在走動、在整理。
很久以前，就有人這樣讀這兩句詩。
:::

:::文學解讀{stance="本站觀點"}
接著讀：「感時花濺淚，恨別鳥驚心。」
「感時」是為這個時局難過。
「恨別」是為和家人分開而傷心。
花開了，杜甫看了卻掉眼淚。
鳥叫了，他聽了反而心裡一驚。
你也可以讀成：連花都在流淚，連鳥都嚇了一跳。
:::

:::史實{source="教育部《重編國語辭典修訂本》" locator="「烽火」條" era="現代研究"}
再讀：「烽火連三月，家書抵萬金。」
烽火，是古時候軍隊用來報警的煙火。
:::

:::文學解讀{stance="本站觀點"}
戰火一直燒，燒到了這年春天還沒停。
這時候一封家裡的信，比一萬兩黃金還珍貴。
:::

:::文學解讀{stance="本站觀點"}
最後兩句：「白頭搔更短，渾欲不勝簪。」
杜甫煩惱的時候，會抓抓頭。
他的頭髮白了，越抓越少。
:::

:::史實{source="教育部《重編國語辭典修訂本》" locator="「簪」條" era="現代研究"}
古時候的人會用簪子，把頭髮或帽子固定好。
:::

:::文學解讀{stance="本站觀點"}
他的頭髮少到，連簪子都快插不住了。
:::

:::教學想像
我們來想像杜甫站在城裡的樣子。
四周很安靜，草長得好高，花開得好漂亮。
他卻一直抓著自己的白頭髮。
你覺得他心裡在想誰？
:::

### 表達活動

我們來玩一個造句遊戲。杜甫看到花就想哭，聽到鳥就心驚。請你也用「看到＿＿，就想起＿＿」說一句話。例如：「看到桌上的布丁，就想起出差的爸爸。」

接著，請你想一個很久沒見面的人。如果只能寄一封很短的信，你會寫哪兩句話？先說出來，再一起寫下來。像杜甫那樣，不一定要寫「我想你」，可以寫你看到的一樣東西。
