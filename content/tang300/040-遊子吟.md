## 深入賞析

### 字詞

:::史實{refs="moe_revised_1"}
「遊子」指離開家鄉、到遠方去的人。
:::

:::史實{refs="moe_variants_1 moe_variants_2"}
題目的「遊」在古書也見「游」字。兩字都是教育部正字；本文依通行題名作「遊」。
:::

:::史實{refs="moe_revised_2"}
「密密」在這裡是細密、緊密，形容針腳縫得又細又緊。
:::

:::文學解讀{stance="白話轉述"}
「意恐遲遲歸」可轉述為：她心裡擔心，出門的人很久才回來。
:::

:::史實{refs="zhang_zhu_shu_2 yang_tang_yin_2"}
清代章燮注：「寸草心，細微也。三春暉，和且普也。」元代張震注《唐音》則說三春暉是「和氣也，所以發育草木，故比慈母」。寸草是小草，比喻兒子微小的心意；三春暉是春天的陽光，比喻母親的恩情。
:::

:::史實{refs="moe_revised_3"}
「三春」是春季的三個月，也就是孟春、仲春、季春。
:::

### 背景

:::史實{refs="hanyu_epitaph_1"}
孟郊字東野，好友韓愈替他寫了墓誌。墓誌說他「年幾五十，始以尊夫人之命來集京師，從進士試」，考上之後「間四年，又命來選，為溧陽尉，迎侍溧上」。去考進士、去當溧陽縣尉，墓誌都說是奉母親之命；當了縣尉，他就把母親接到溧陽奉養。
:::

:::史實{refs="hanyu_jian_shi_1 meng_zhai_di_1"}
韓愈寫詩推薦他時說：「酸寒溧陽尉，五十幾何耄？孜孜營甘旨，辛苦久所冒。」孟郊自己在考上進士後回家的詩裡寫道：「昔歲辭親淚」「慈親誡志就」。
:::

:::史實{refs="xin_tang_shu_1 wu_jingxi_1"}
北宋編成的《新唐書》說他「年五十，得進士第」，後來的選本多照這個說法。南宋吳子良依墓誌的卒年與《唐登科記》推算，認為他考上時是四十六歲；吳子良也指出，孟郊集裡有〈落第〉〈再下第〉，可見他在這之前已經考過不只一次。
:::

:::史實{refs="lu_guimeng_1 xin_tang_shu_1"}
晚唐陸龜蒙記下一則傳聞：孟郊在溧陽常到水邊苦吟，公務荒廢，縣令只好另請代理的縣尉，分走他一半的俸祿。陸龜蒙說，這是他小時候在溧陽聽一位白髮老書吏講的。《新唐書》後來把這則傳聞寫進孟郊的傳。
:::

:::史實{refs="quan_tang_shi_1 meng_dongye_1 yue_fu_shi_ji_1"}
清代《全唐詩》在題目下注「自註：迎母溧上作」；明刊本孟郊集與《樂府詩集》沒有這條題注。這裡只記各版本的文字，不據「自註」兩字確定作者親註，也不據此確定寫作年份。
:::

:::史實{refs="shi_zhu_su_shi_1 jin_xiu_1"}
宋代已經有人把這首詩和溧陽尉連在一起。蘇軾送新茶給朋友，讓他帶回去孝敬母親，詩的第一句就是「縫衣付與溧陽尉」；南宋類書《錦繡萬花谷》也寫「孟郊為溧陽尉，有遊子吟」。本文不採確切繫年。
:::

:::文學解讀{stance="本站觀點"}
題注說「迎母」，詩裡寫「臨行」，兩個場景並不相同。若把兩者連起來，可以想像詩人迎母時回想離家的情景；這只是讀法，不能當成寫作經過。
:::

:::史實{refs="yue_fu_shi_ji_3"}
「遊子吟」是樂府舊題。宋代郭茂倩把這首詩收在〈雜曲歌辭〉，題下引漢代蘇武詩「請為遊子吟，泠泠一何悲」，說明這個題目原本就是寫離家遠行的悲歌。
:::

### 技巧

:::史實{refs="guang_yun_2"}
全詩六句，隔句押平聲微韻，韻腳是衣、歸、暉，一韻到底。今天國語讀起來，歸、暉仍然押韻，衣已經不押。
:::

:::史實{refs="guang_yun_3"}
依《廣韻》聲調，六句的平仄是：平仄仄平仄、平仄平仄平、平平仄仄平、仄仄平平平、平平仄仄平、仄仄平平平。
:::

:::文學解讀{stance="本站觀點"}
六句的篇幅和所列平仄，都與常見的近體絕句或律詩格式不同。若依近體詩避免三平調的規則來看，第四、六句也不合；《唐詩三百首》把它歸在五言樂府。
:::

:::文學解讀{stance="通行說法" refs="zhang_zhu_shu_2"}
章燮把全詩分成兩解：前四句是「一解」，說「慈母待子之情，刻刻不忘」；後兩句是「二解」，注明「比也」，說「父母之恩，人子不能寸報」。前四句直接敘事，後兩句改用比喻。
:::

:::文學解讀{stance="本站觀點"}
前兩句只有名詞，沒有動詞：母親手裡的線，遊子身上的衣。線從一個人的手裡，到了另一個人的身上，母子的牽連就在這一根線上。第三句才出現動作「縫」，第四句才說出心事「恐」。
:::

:::文學解讀{stance="本站觀點"}
「密密」與「遲遲」兩組疊字前後呼應：針腳越密，表示母親心裡預想的歸期越遠。最後兩句的對比更懸殊，一邊是一寸長的草，一邊是整整三個月的春光。末句是反問：小草的心意，怎麼報答得了春天的陽光？答案就藏在問句裡。
:::

:::文學解讀{stance="通行說法" refs="tang_shi_gui_1 tang_shi_jing_1"}
《唐詩歸》所見鍾惺評語有一字書影難辨，暫錄作「仁孝之言，自然風雅」，其中「仁」字待核。陸時雍則說它「不乏古意」。兩人看重的都是它的樸素，不靠雕琢，卻有古詩的味道。
:::

### 情感

:::文學解讀{stance="通行說法" refs="shen_tang_shi_1"}
沈德潛在詩後評：「即欲報之德，昊天罔極。」這兩句出自《詩經·蓼莪》，說想報答父母的恩德，恩德卻像天一樣沒有邊際。照這個讀法，末兩句寫的是報答不完的母恩。
:::

:::文學解讀{stance="本站觀點"}
詩裡沒有一個字寫眼淚，也沒有一個字說愛。母親沒有說話，只是縫衣；詩把她的擔心寫進每一個針腳。讀者也可以想像，出門的人往後想起這一幕。
:::

:::文學解讀{stance="本站觀點"}
「報不完」不必讀成虧欠。小草不必還給陽光什麼，陽光照它，它就長大。和孩子讀這首詩時，重點可以放在「被人默默照顧」的感覺，而不是「你要孝順」的要求。
:::

### 比較閱讀

:::史實{refs="meng_dongye_3 wen_yuan_ying_hua_1 quan_tang_shi_4"}
所見《孟東野詩集》收有一首〈遊子〉：「萱草生堂階，遊子行天涯。慈親倚堂門，不見萱草花。」《文苑英華》署聶夷中名下，《全唐詩》兩人名下都收；各版本署名不同，這裡不定作者。
:::

:::史實{refs="zhou_zhi_lin_1"}
後人常用萱草代稱母親。明代周嬰引《野客叢談》指出，《詩經》的舊注只說萱草讓人忘憂、種在北堂，「初未嘗言母也」；他認為以萱比母，是從〈遊子〉這首詩來的。
:::

:::文學解讀{stance="本站觀點"}
兩首詩站的位置相反。〈遊子吟〉從兒子這邊寫，記得的是母親縫衣的手；〈遊子〉從母親這邊寫，她倚著門望，連階前的萱草都看不見了。放在一起讀，就是同一場離別的兩端。
:::

## 親子共學

### 開場

:::教學想像
我們來想像一件有人補過的衣服。
穿上它的人，會想到什麼？
你可以想像一個角色，也可以跳過。
:::

:::教學想像
我們來想像一下。
明天你要去很遠的地方，要住好久。
故事裡的照顧者會幫你做什麼？
:::

### 共讀

:::史實{refs="hanyu_epitaph_1"}
寫這首詩的人叫孟郊，是唐朝的詩人。
墓誌記下他去考試，後來到外地當官。
墓誌也說，他把母親接來同住。
:::

:::文學解讀{stance="白話轉述"}
我們讀第一句：「慈母手中線。」
慈母，是詩裡疼孩子的母親。
詩裡的母親手裡拿著線。
:::

:::史實{refs="moe_revised_1"}
第二句：「遊子身上衣。」
遊子，是離開家、到遠方去的人。
:::

:::文學解讀{stance="本站觀點"}
母親手裡的線，成了遊子身上的衣服。
這兩句裡，一個是母親，一個是遊子。
中間連著的，就是那一條線。
:::

:::文學解讀{stance="白話轉述"}
第三句：「臨行密密縫。」
臨行，就是快要出門的時候。
遊子要走了，母親一針一針縫得很密。
:::

:::文學解讀{stance="白話轉述"}
第四句：「意恐遲遲歸。」
意恐，是心裡擔心。
母親擔心遊子很久才回來。
:::

:::教學想像
我們來想像詩裡母親縫衣的樣子。
也許燈還亮著。
她為什麼要縫得那麼密？
你猜猜看，她心裡在想什麼？
:::

:::史實{refs="zhang_zhu_shu_2 moe_revised_4"}
最後兩句：「誰言寸草心，報得三春暉？」
寸草，是很短很短的小草。
三春暉，是整個春天的陽光。
:::

:::文學解讀{stance="白話轉述"}
小草靠著陽光才長大。
詩人在問：誰說小草的一點心意，
報答得了整個春天的陽光呢？
詩把遊子比成小草，把母愛比成陽光。
:::

:::教學想像
如果你是那棵小草，
每天曬著暖暖的太陽，
你想對太陽說什麼？
:::

### 提問

```yaml questions
- level: 提取
  question: 詩裡的遊子出門前，母親在做什麼？
  likely_answers:
    - answer: 在縫衣服。
      follow_up: 對。她縫得怎麼樣？詩裡用了哪兩個字？
    - answer: 在送他出門。
      follow_up: 快要出門了，可是出門前一晚，她手上在忙什麼？我們再讀一次第三句。
    - answer: 在拿線。
      follow_up: 對，線在她手裡。她拿線要做什麼呢？
- level: 推論
  question: 詩裡的母親為什麼縫得很密？
  likely_answers:
    - answer: 怕衣服破掉。
      follow_up: 對。為什麼她特別怕衣服破掉？
    - answer: 因為孩子要走很久。
      follow_up: 你是從哪一句看出來的？
    - answer: 因為天氣很冷。
      follow_up: 也有可能。詩裡有沒有說媽媽在擔心什麼？
- level: 詮釋整合
  question: 詩裡為什麼把遊子比成小草？
  likely_answers:
    - answer: 因為小草很小，太陽很大。
      follow_up: 對，一個很小，一個很大。這樣比，想說的是什麼？
    - answer: 因為小草要曬太陽才會長大。
      follow_up: 說得好。那孩子是靠什麼長大的？
    - answer: 不知道。
      follow_up: 沒關係。你想想看，小草可以還給太陽什麼東西嗎？
- level: 評估
  question: 這首詩沒有寫「我愛你」，你覺得讀的人感覺得到愛嗎？為什麼？
  likely_answers:
    - answer: 感覺得到，因為詩裡的母親縫得很用心。
      follow_up: 對。你覺得做一件事，有時候比說一句話更有感覺嗎？
    - answer: 感覺不太到，應該直接說出來。
      follow_up: 這也是一種想法。你覺得故事裡還能怎麼表達？
    - answer: 有，最後兩句就在說。
      follow_up: 你看得很仔細。那前面四句，是用什麼方法讓我們感覺到的？
```

### 表達活動

我們來學詩裡的兩句話。
詩寫「慈母手中線，遊子身上衣」。
線從母親手裡，到了遊子身上。
請說：「＿＿手中的＿＿，變成＿＿的＿＿。」
可以想像一個照顧者和一個角色。
例如：「廚師手中的米，變成旅人的飯。」
也可以跳過這一題。

再來玩「小草與陽光」。
想像一棵小草，和照著它的陽光。
試著寫一句小詩，說說它們的關係。
