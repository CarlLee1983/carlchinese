## 深入賞析

### 字詞

:::史實{source="教育部《重編國語辭典修訂本》" locator="「遊子」條" url="https://dict.revised.moe.edu.tw/dictView.jsp?ID=154057&la=0&powerMode=0" era="現代研究"}
「遊子」指離開家鄉、到遠方去的人。
:::

:::史實{source="教育部《異體字字典》" locator="「遊」字（A04158）；「游」字（A02249）" url="https://dict.variants.moe.edu.tw/dictView.jsp?ID=45434" era="現代研究"}
題目的「遊」也有人寫作「游」。兩字都是教育部正字，古書常常通用，今天才分工：在水裡活動的意思用「游」，其他用「遊」。
:::

:::史實{source="教育部《重編國語辭典修訂本》" locator="「密密」條" url="https://dict.revised.moe.edu.tw/dictView.jsp?ID=31020&la=0&powerMode=0" era="現代研究"}
「密密」在這裡是細密、緊密，形容針腳縫得又細又緊。
:::

:::文學解讀{stance="本站觀點"}
「意恐遲遲歸」的「意」是心裡，「恐」是擔心，「遲遲歸」是很久才回來。母親把針腳縫得密，是怕兒子在外頭待得久，衣服先穿破了。
:::

:::史實{source="章燮《唐詩三百首註疏》；楊士弘《唐音》（張震注）" locator="卷一；卷十二" url="https://commons.wikimedia.org/w/index.php?title=File:NTUL-9910002735_%E5%94%90%E8%A9%A9%E4%B8%89%E7%99%BE%E9%A6%96%E8%A8%BB%E7%96%8F_%E5%85%AD%E5%8D%B7_v.1.pdf&page=33" era="後世古籍；後世古籍"}
清代章燮注：「寸草心，細微也。三春暉，和且普也。」元代張震注《唐音》則說三春暉是「和氣也，所以發育草木，故比慈母」。寸草是小草，比喻兒子微小的心意；三春暉是春天的陽光，比喻母親的恩情。
:::

:::史實{source="教育部《重編國語辭典修訂本》" locator="「三春」條" url="https://dict.revised.moe.edu.tw/dictView.jsp?ID=144757&la=0&powerMode=0" era="現代研究"}
「三春」是春季的三個月，也就是孟春、仲春、季春。
:::

### 背景

:::史實{source="韓愈〈貞曜先生墓誌銘〉" locator="《五百家注昌黎文集》卷二十九" url="https://zh.wikisource.org/wiki/五百家注昌黎文集_(四庫全書本)/卷29" era="同時代"}
孟郊字東野，好友韓愈替他寫了墓誌。墓誌說他「年幾五十，始以尊夫人之命來集京師，從進士試」，考上之後「間四年，又命來選，為溧陽尉，迎侍溧上」。去考進士、去當溧陽縣尉，墓誌都說是奉母親之命；當了縣尉，他就把母親接到溧陽奉養。
:::

:::史實{source="韓愈〈薦士〉；孟郊〈擢第後東歸書懷獻座主呂侍御〉" locator="《昌黎先生集》卷二；《孟東野詩集》卷六" url="https://zh.wikisource.org/wiki/薦士" era="同時代；同時代"}
韓愈寫詩推薦他時說：「酸寒溧陽尉，五十幾何耄？孜孜營甘旨，辛苦久所冒。」孟郊自己在考上進士後回家的詩裡寫道：「昔歲辭親淚」「慈親誡志就」。
:::

:::史實{source="《新唐書》；吳子良《荆溪林下偶談》" locator="卷一七六〈孟郊傳〉；卷一「孟郊年四十六登第」條" url="https://zh.wikisource.org/wiki/荆溪林下偶談_(四庫全書本)/卷1" era="後世古籍；後世古籍"}
北宋編成的《新唐書》說他「年五十，得進士第」，後來的選本多照這個說法。南宋吳子良依墓誌的卒年與《唐登科記》推算，認為他考上時是四十六歲；吳子良也指出，孟郊集裡有〈落第〉〈再下第〉，可見他在這之前已經考過不只一次。
:::

:::史實{source="陸龜蒙〈書李賀小傳後〉；《新唐書》" locator="《全唐文》卷八〇一；卷一七六〈孟郊傳〉" url="https://zh.wikisource.org/wiki/書李賀小傳後" era="後世古籍；後世古籍"}
晚唐陸龜蒙記下一則傳聞：孟郊在溧陽常到水邊苦吟，公務荒廢，縣令只好另請代理的縣尉，分走他一半的俸祿。陸龜蒙說，這是他小時候在溧陽聽一位白髮老書吏講的。《新唐書》後來把這則傳聞寫進孟郊的傳。
:::

:::史實{source="《全唐詩》（四庫全書本）；《孟東野詩集》（四部叢刊景明弘治本）；郭茂倩《樂府詩集》" locator="卷三七二；卷第一；卷六十七" url="https://commons.wikimedia.org/w/index.php?title=File:CADAL06060036_%E5%BE%A1%E5%AE%9A%E5%85%A8%E5%94%90%E8%A9%A9%C2%B7%E5%8D%B7%E4%B8%89%E7%99%BE%E4%B8%83%E5%8D%81%E4%B8%80~%E5%8D%B7%E4%B8%89%E7%99%BE%E4%B8%83%E5%8D%81%E4%BA%94.djvu&page=43" era="後世古籍；後世古籍；後世古籍"}
清代《全唐詩》在題目下注「自註：迎母溧上作」，意思是孟郊自己注明這首詩寫於到溧陽迎接母親時。不過明刊本孟郊集與宋代的《樂府詩集》都沒有這條注，它從哪裡來，目前查不到。
:::

:::史實{source="《施注蘇詩》；《錦繡萬花谷》" locator="卷二十八；前集卷十四" url="https://zh.wikisource.org/wiki/施注蘇詩_(四庫全書本)/卷28" era="後世古籍；後世古籍"}
宋代已經有人把這首詩和溧陽尉連在一起。蘇軾送新茶給朋友，讓他帶回去孝敬母親，詩的第一句就是「縫衣付與溧陽尉」；南宋類書《錦繡萬花谷》也寫「孟郊為溧陽尉，有遊子吟」。查過的古籍注本，都沒有替這首詩寫明年份。
:::

:::文學解讀{stance="本站觀點"}
題注說是「迎母」，詩裡寫的卻是「臨行」：兒子要出門，母親在燈下趕著縫衣。兩個場景並不相同。比較說得通的讀法是，詩人在接母親同住的時候，回想起當年離家的那一夜；但這只是推想，不能當成寫作經過。
:::

:::史實{source="郭茂倩《樂府詩集》" locator="卷六十七〈雜曲歌辭〉" url="https://zh.wikisource.org/wiki/樂府詩集_(四庫全書本)/卷067" era="後世古籍"}
「遊子吟」是樂府舊題。宋代郭茂倩把這首詩收在〈雜曲歌辭〉，題下引漢代蘇武詩「請為遊子吟，泠泠一何悲」，說明這個題目原本就是寫離家遠行的悲歌。
:::

### 技巧

:::史實{source="《廣韻》" locator="上平聲八微：衣，於希切；歸，舉韋切；暉，許歸切" url="https://ytenx.org/kyonh/yonhmiuk/%E5%BE%AE/" era="後世古籍"}
全詩六句，隔句押平聲微韻，韻腳是衣、歸、暉，一韻到底。今天國語讀起來，歸、暉仍然押韻，衣已經不押。
:::

:::史實{source="《廣韻》" locator="各字聲調" url="https://ytenx.org/kyonh/" era="後世古籍"}
依《廣韻》聲調，六句的平仄是：平仄仄平仄、平仄平仄平、平平仄仄平、仄仄平平平、平平仄仄平、仄仄平平平。
:::

:::文學解讀{stance="本站觀點"}
六句的篇幅不是近體詩的四句或八句，第四、六句又以三個平聲收尾，這是近體詩避忌的「三平調」。它是不講近體格律的古體樂府，《唐詩三百首》也把它歸在五言樂府。
:::

:::文學解讀{stance="通行說法" by="章燮《唐詩三百首註疏》卷一"}
章燮把全詩分成兩解：前四句是「一解」，說「慈母待子之情，刻刻不忘」；後兩句是「二解」，注明「比也」，說「父母之恩，人子不能寸報」。前四句直接敘事，後兩句改用比喻。
:::

:::文學解讀{stance="本站觀點"}
前兩句只有名詞，沒有動詞：母親手裡的線，遊子身上的衣。線從一個人的手裡，到了另一個人的身上，母子的牽連就在這一根線上。第三句才出現動作「縫」，第四句才說出心事「恐」。
:::

:::文學解讀{stance="本站觀點"}
「密密」與「遲遲」兩組疊字前後呼應：針腳越密，表示母親心裡預想的歸期越遠。最後兩句的對比更懸殊，一邊是一寸長的草，一邊是整整三個月的春光。末句是反問：小草的心意，怎麼報答得了春天的陽光？答案就藏在問句裡。
:::

:::文學解讀{stance="通行說法" by="鍾惺、譚元春《唐詩歸》卷三十一（引鍾惺）；陸時雍《唐詩鏡》卷四十"}
明代鍾惺評這首詩：「仁孝之言，自然風雅。」陸時雍則說它「不乏古意」。兩人看重的都是它的樸素，不靠雕琢，卻有古詩的味道。
:::

### 情感

:::文學解讀{stance="通行說法" by="沈德潛《重訂唐詩別裁集》卷四"}
沈德潛在詩後評：「即欲報之德，昊天罔極。」這兩句出自《詩經·蓼莪》，說想報答父母的恩德，恩德卻像天一樣沒有邊際。照這個讀法，末兩句寫的是報答不完的母恩。
:::

:::文學解讀{stance="本站觀點"}
詩裡沒有一個字寫眼淚，也沒有一個字說愛。母親沒有說話，只是低頭縫衣；她的擔心不說出口，而是縫進每一個針腳。兒子多年後想起來，才明白那一針一線的意思。
:::

:::文學解讀{stance="本站觀點"}
「報不完」不必讀成虧欠。小草不必還給陽光什麼，陽光照它，它就長大。和孩子讀這首詩時，重點可以放在「被人默默照顧」的感覺，而不是「你要孝順」的要求。
:::

### 比較閱讀

:::史實{source="《孟東野詩集》（四庫全書本）；《文苑英華》（四庫全書本）；《全唐詩》（四庫全書本）" locator="卷三；卷二〇七；卷三七四、卷六三六" url="https://zh.wikisource.org/wiki/文苑英華_(四庫全書本)/卷0207" era="後世古籍；後世古籍；後世古籍"}
孟郊集裡還收有一首〈遊子〉：「萱草生堂階，遊子行天涯。慈親倚堂門，不見萱草花。」不過宋代的《文苑英華》把這首詩歸在聶夷中名下，《全唐詩》則兩人都收，作者至今難定。
:::

:::史實{source="周嬰《巵林》（引《野客叢談》）" locator="卷三「北堂」條" url="https://zh.wikisource.org/wiki/巵林_(四庫全書本)/卷03" era="後世古籍"}
後人常用萱草代稱母親。明代周嬰引《野客叢談》指出，《詩經》的舊注只說萱草讓人忘憂、種在北堂，「初未嘗言母也」；他認為以萱比母，是從〈遊子〉這首詩來的。
:::

:::文學解讀{stance="本站觀點"}
兩首詩站的位置相反。〈遊子吟〉從兒子這邊寫，記得的是母親縫衣的手；〈遊子〉從母親這邊寫，她倚著門望，連階前的萱草都看不見了。放在一起讀，就是同一場離別的兩端。
:::

## 親子共學

### 開場

:::教學想像
你有沒有一件衣服，是家人幫你挑的、補過的，或是織的？
穿上它的時候，你會想起誰？
:::

:::教學想像
我們來想像一下。
明天你要去很遠的地方，要住好久。
今天晚上，家裡的大人會幫你做什麼？
:::

### 共讀

:::史實{source="韓愈〈貞曜先生墓誌銘〉" locator="《五百家注昌黎文集》卷二十九" url="https://zh.wikisource.org/wiki/五百家注昌黎文集_(四庫全書本)/卷29" era="同時代"}
寫這首詩的人叫孟郊，是唐朝的詩人。
他快五十歲才考上進士，去外地當小官。
當了官，他就把媽媽接來一起住。
:::

:::文學解讀{stance="本站觀點"}
我們讀第一句：「慈母手中線。」
慈母，就是很疼孩子的媽媽。
媽媽的手裡，拿著一條線。
:::

:::史實{source="教育部《重編國語辭典修訂本》" locator="「遊子」條" url="https://dict.revised.moe.edu.tw/dictView.jsp?ID=154057&la=0&powerMode=0" era="現代研究"}
第二句：「遊子身上衣。」
遊子，是離開家、到遠方去的人。
:::

:::文學解讀{stance="本站觀點"}
媽媽手裡的線，變成了遊子身上的衣服。
這兩句裡，一個是媽媽，一個是孩子。
中間連著的，就是那一條線。
:::

:::文學解讀{stance="本站觀點"}
第三句：「臨行密密縫。」
臨行，就是快要出門的時候。
孩子要走了，媽媽一針一針，縫得好密。
:::

:::文學解讀{stance="本站觀點"}
第四句：「意恐遲遲歸。」
意恐，是心裡擔心。
媽媽擔心孩子很久很久才回來。
:::

:::教學想像
我們來想像媽媽縫衣服的樣子。
夜深了，大家都睡了，燈還亮著。
她為什麼要縫得那麼密？
你猜猜看，她心裡在想什麼？
:::

:::史實{source="章燮《唐詩三百首註疏》；教育部《重編國語辭典修訂本》" locator="卷一；「三春暉」條" url="https://dict.revised.moe.edu.tw/dictView.jsp?ID=144759&la=0&powerMode=0" era="後世古籍；現代研究"}
最後兩句：「誰言寸草心，報得三春暉。」
寸草，是很短很短的小草。
三春暉，是整個春天的陽光。
:::

:::文學解讀{stance="本站觀點"}
小草靠著陽光才長大。
詩人在問：誰說小草的一點心意，
報答得了整個春天的陽光呢？
孩子就像小草，媽媽的愛就像陽光。
:::

:::教學想像
如果你是那棵小草，
每天曬著暖暖的太陽，
你想對太陽說什麼？
:::

### 表達活動

我們來學孟郊的句子，自己做一句。孟郊寫「慈母手中線，遊子身上衣」。線從媽媽的手裡，到了孩子的身上。請你也說一句：「＿＿手中的＿＿，變成我的＿＿。」例如：「阿嬤手中的米，變成我便當裡的飯。」這個人可以是家裡任何一個照顧你的人。

接著，我們來玩「小草與陽光」。請你想一個每天照顧你的人或東西。你平常很少注意它，對不對？說一說，它像不像陽光。再試著用一句話，說出你想對它說的話。
