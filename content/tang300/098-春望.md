## 深入賞析

### 字詞

:::文學解讀{stance="本站觀點"}
「國破」可以先讀作京城失陷，再感到整個國家的殘破。「山河在」的「在」，字面是還在，語氣卻像是「只剩下」。
:::

:::文學解讀{stance="通行說法" refs="qiu_du_shi_4"}
「烽火連三月」的「三月」，舊注有兩種讀法。仇兆鰲引宋人黃鶴的看法，認為指季春三月，也就是戰火一直延燒到這年暮春；他同時記下趙氏的另一說，把它算成從叛亂爆發起連續三個月，並引顧宸的考證，指出那個時間點長安尚未失陷，判定趙說不合史實。
:::

:::文學解讀{stance="本站觀點"}
本站採「季春三月」的讀法，但不必把「三」讀死。和下句的「萬金」對照，「連三月」寫的是時間拖得長，「抵萬金」寫的是價值抬得高，兩個數字都在誇張戰亂中的煎熬。
:::

:::史實{refs="moe_revised_2"}
「渾欲不勝簪」：渾，簡直；不勝，承受不了。簪是古人用來綰髮或固定頭冠的頭飾。
:::

:::文學解讀{stance="本站觀點"}
「欲」是快要。末句寫頭髮少到連簪子都快插不住，也讓人感到他的愁苦。
:::

### 背景

:::史實{refs="jiu_tang_shu_1"}
天寶十四載（755）十一月，安祿山起兵叛唐；次年六月，哥舒翰兵敗，潼關失守，玄宗出奔往蜀。至德二載（757）九月，官軍收復長安。
:::

:::史實{refs="xin_tang_shu_du_1"}
《新唐書》記載：安祿山之亂時，杜甫避難到三川，家眷安置在鄜州；肅宗即位後，他從鄜州換上粗衣想投奔朝廷，途中落入叛軍手中。至德二年，他逃到鳳翔謁見肅宗，被任命為右拾遺。這部史書成書於北宋，距杜甫過世約三百年。
:::

:::史實{refs="qiu_du_shi_5"}
清代仇兆鰲引宋人黃鶴的說法，把〈春望〉繫於至德二載三月、杜甫陷在叛軍中的時候；同卷〈憶幼子〉的題下注也說杜甫這年春天在長安。這是注家依詩意與史事推定的年代。
:::

:::史實{refs="dufu_shu_huai_1"}
杜甫自己在〈述懷〉裡回顧這段經歷：「去年潼關破，妻子隔絕久。今夏草木長，脫身得西走。」詩中又說：「自寄一封書，今已十月後。」信寄出後十個月，仍沒有家人的回音。
:::

### 技巧

:::文學解讀{stance="通行說法" refs="sima_xu_shi_hua_1"}
北宋司馬光拿這首詩的前四句說明古人作詩「意在言外」。他的解讀是：說山河還在，等於說除此之外什麼都沒了；說草木長得深，等於說城裡沒有人；花和鳥本是讓人愉快的東西，詩人卻見了落淚、聽了心驚，時局如何便不言可喻。詩人不直說「長安殘破」，讓讀者自己推出來。
:::

:::文學解讀{stance="通行說法" refs="qiu_du_shi_4"}
仇兆鰲把全詩分成兩半：前四句寫春望所見的景，後四句寫遭亂思家的情。他也引元人趙汸的看法，認為「烽火」句接著「感時」，「家書」句接著「恨別」，前後兩聯一一呼應。
:::

:::文學解讀{stance="本站觀點"}
「感時花濺淚，恨別鳥驚心」可以有兩種讀法。一種把花鳥擬人：花也在流淚，鳥也被驚動。另一種以詩人為主語：看到花，詩人淚水濺落；聽到鳥叫，詩人心頭一驚。兩種讀法並不衝突，詩句的好處正在於主語沒有說死，人和景的界線因此模糊了。
:::

:::史實{refs="guang_yun_1"}
依《廣韻》各韻腳所屬的侵韻，本詩的深、心、金、簪同押。
:::

:::文學解讀{stance="本站觀點"}
中間兩聯對仗：「感時」對「恨別」，「花濺淚」對「鳥驚心」；「烽火」對「家書」，「連三月」對「抵萬金」。工整的形式裝著紛亂的時局，形式越穩，越顯出內容的不安。
:::

:::文學解讀{stance="本站觀點"}
全詩的視線一路收窄：從山河、城池，到花鳥，到戰火與家書，最後落在詩人自己頭上稀疏的白髮與一根插不住的簪子。國、家、身三層，從最大的寫到最小的，最小的那根簪子反而最刺眼。
:::

### 情感

:::文學解讀{stance="本站觀點"}
這首詩的悲傷有兩個來源：國家殘破，以及與家人分離。杜甫沒有把兩者分開，也沒有喊口號。他寫的是一個被困在城裡的中年人，在春天看到花開鳥鳴，卻只覺得刺痛。
:::

:::文學解讀{stance="本站觀點"}
結尾不寫報國的決心，而寫自己老了、頭髮少了。這種無力感很誠實：一個人在亂世裡能做的事很有限，能感受到的痛卻很具體。讀者不必把它讀成悲壯，讀成一個父親、一個丈夫的焦慮也成立。
:::

### 比較閱讀

:::文學解讀{stance="通行說法" refs="qiu_du_shi_4"}
「不勝簪」的說法有來歷。仇兆鰲在注中引了南朝鮑照的詩句「白髮零落不勝簪」，杜甫的末句與之相近。
:::

:::史實{refs="dufu_yi_you_zi_1"}
杜甫還寫了〈憶幼子〉：「驥子春猶隔，鶯歌暖正繁。別離驚節換，聰慧與誰論。」
:::

:::史實{refs="qiu_du_shi_6"}
仇兆鰲把〈憶幼子〉和〈春望〉繫在同一年春天，並注明驥子是杜甫幼子宗武的小名。
:::

:::文學解讀{stance="本站觀點"}
把兩首詩放在一起讀，〈春望〉的「恨別鳥驚心」就有了具體的臉孔。〈憶幼子〉裡，鶯鳥唱得正熱鬧，提醒他季節又換了，他想的是那個聰明的孩子身邊沒有人可以說話。〈述懷〉裡「反畏消息來」一句，更寫出等家書等到怕收到信的心情，可以和「家書抵萬金」對照著讀。
:::

## 親子共學

### 開場

:::教學想像
我們來想像一下。
想像一個人去很遠的營隊。
那裡不能打電話，也不能傳訊息。
他會想念誰？
可以自己想，也可以跳過。
:::

:::教學想像
再想像外面發生危險的事。
這個人回不了家，也不知道親友好不好。
他收到一封信，會有什麼感覺？
這首詩寫到戰亂中的分離。
:::

### 共讀

:::史實{refs="xin_tang_shu_du_1"}
寫這首詩的人叫杜甫，是唐朝的詩人。
那時候有人帶兵造反，國家發生了大戰亂。
杜甫的太太和孩子住在另一個地方。
他一個人出門，半路上被叛軍抓住了。
:::

:::史實{refs="qiu_du_shi_7"}
清代注家把這首詩放在戰亂中的春天。
詩的名字叫〈春望〉。
:::

:::文學解讀{stance="白話轉述"}
我們讀前兩句：「國破山河在，城春草木深。」
京城失陷了，山和河卻還在。
春天到了，城裡的草和樹長得又高又密。
:::

:::文學解讀{stance="通行說法" refs="sima_xu_shi_hua_1"}
司馬光讀到草木深，想到城裡人少。
:::

:::文學解讀{stance="白話轉述"}
接著讀：「感時花濺淚，恨別鳥驚心。」
「感時」是為這個時局難過。
「恨別」是為和家人分開而傷心。
花開了，他看了卻掉眼淚。
鳥叫了，他聽了卻心裡一驚。
:::

:::文學解讀{stance="本站觀點"}
也可以讀成花在流淚，鳥被嚇了一跳。
:::

:::史實{refs="moe_revised_3"}
再讀：「烽火連三月，家書抵萬金。」
烽火，是古時候軍隊用來報警的煙火。
:::

:::文學解讀{stance="白話轉述"}
戰火拖了很久，到了春天還沒停。
這時候一封家裡的信，比一萬兩黃金還珍貴。
:::

:::文學解讀{stance="白話轉述"}
最後兩句：「白頭搔更短，渾欲不勝簪。」
詩裡寫他抓著白頭髮。
頭髮被他一抓，好像更少了。
:::

:::史實{refs="moe_revised_4"}
古時候的人會用簪子，把頭髮或帽子固定好。
:::

:::文學解讀{stance="白話轉述"}
他的頭髮少到，連簪子都快插不住了。
:::

:::教學想像
我們來想像詩人站在城裡。
四周很安靜，草長得好高，花開得好漂亮。
他卻一直抓著自己的白頭髮。
你覺得他心裡在想誰？
:::

      follow_up: 黃金可以買很多東西。那有什麼是黃金買不到的？
- level: 評估
  question: 這首詩沒有直接說「我好想家」。你覺得不直接說好，還是直接說好？
  likely_answers:
